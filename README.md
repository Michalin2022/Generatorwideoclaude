# Generator Wideo Claude
Claude (ten darmowy) od dziś może generować wideo! 
# Jak to działa? 
Po wejściu na stronę [insetup] znajdujesz „**Ściąga formatu**”. Tą instrukcję piszesz Claudowi a następnie piszesz np. Używając tej instrukcji wygeneruj mi wideo jak powstaje **RAM** po niedługim czasie Claude zwróci kod który wklejamy na stronę i oglądamy jeśli się podoba klikamy nagraj wideo, co faktycznie nagra film (zamiast zwykłego podglądu). Nagrywanie trwa tyle ile trwa wideo. Po nagraniu możesz zapisać wideo i zrobione!
# To nie jest perfekcyjne! 
Claude nie doda obrazków ponieważ przez kod nie może (chyba że zrobi je od zera). Wideo **NIE BĘDZIE** wyglądało tak jak zrobiłby to Claude Pro.
